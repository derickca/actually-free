# Windows 11 evidence follow-up — 12 October 2026

## Coverage and limits

All 468 published Windows records were checked against their download pages and selected requirement pages from the same-day audit. Accepted candidates were checked for app identity and an explicit support/requirements statement. This is a bounded documentation review, not proof that every app works.

Publisher/project evidence: **71**. Distributor-only evidence: **60**. Unverified: **336**. Explicit standard-taskbar incompatibility: **1**. Locally installation-tested: **0**.

Generic PortableApps platform pages, GitHub topic pages, Winget client requirements, unrelated product advertisements, feature/changelog mentions and user comments were rejected as support evidence. For example, cdrtfe must not inherit a SpeedCommander advertisement; VSCodium must not inherit Winget requirements; Espanso/HexChat/System Informer must not inherit GitHub topic-page text.

Distributor evidence applies only to the linked portable package. OpenTTD and Stellarium have architecture-limited evidence, noted on their records. No evidence either way doesn't mean an app is incompatible.
